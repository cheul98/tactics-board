# 축구 작전판 (Tactics Board)

위에서 내려다본 축구장에 선수·공·화살표를 배치하고, 장면(프레임)을 이어 붙여 **애니메이션 영상(MP4/WebM)** 과 **이미지(PNG)** 로 저장하는 전술 분석 도구입니다. 설치 없이 브라우저에서 바로 동작합니다.

## 주요 기능
- 정규 규격(105×68m) 경기장, 잔디·화이트보드·다크 스타일
- 포메이션 프리셋(4-3-3, 4-4-2, 4-2-3-1, 3-5-2, 3-4-3, 5-3-2)
- 침투·패스·드리블 화살표와 곡선 경로, 구역 표시, 메모
- 화살표를 따라 다음 장면을 자동 생성하고 선수·공을 곡선으로 이동
- 구단 엠블럼 업로드(흰 배경 자동 제거, 크기 자동 통일)
- 팀 프리셋(팀명·색·엠블럼·명단) 저장과 불러오기
- 기본 비율 또는 16:9(1920×1080) 저장

## 사용 방법
1. 팀 탭에서 포메이션과 팀 정보를 정합니다.
2. 선수 위에서 시작해 화살표를 그리고 `M`(화살표대로 다음 장면)을 누릅니다.
3. 재생으로 확인하고 **동영상 저장**을 누릅니다.

작업 내용은 브라우저에 자동 저장되며, `프로젝트 저장`으로 .json 파일을 받아 백업할 수 있습니다.
동영상 저장은 최신 Chrome / Edge에서 MP4로 저장됩니다.
